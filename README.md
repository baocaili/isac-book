## 四、写作规范（`_build/GUIDE.md`）

每章统一采用六步讲授法：

> 直观引入 → 数学建模 → 算法详尽步骤 → 伪代码（```text，类 Python + 中文注释）→ Mermaid 流程图 → 带数值的完整算例 → 讨论/对比表

每章末尾固定包含：
- `## 本章小结`
- `## 习题`（A 基础概念 6–8 题 / B 推导计算 5–7 题 / C 算法编程 2–3 题）
- `## 答案与解析`（**逐题完整推导**，计算题给出完整数值步骤）

统一约定：公式用 LaTeX 并编号 `\tag{章-N}`；图题/表题置于代码块前一行；符号全书统一（见 `GUIDE.md` 第 5 节）。
